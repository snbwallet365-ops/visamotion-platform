# VisaMOTion Website Build

## Files

- `visamotion-website.html` - Long VisaMOTion public website with services, pricing estimator, FAQ, enquiry modal, booking flow, chat assistant, cookie preference, and staff-admin link.
- `visamotion-staff-admin.html` - VisaMOTion internal staff workspace with demo login, dashboard, companies, compliance, accounting, invoices, documents, messages, billing, team, settings, notifications, and responsive mobile navigation.

## Demo access

Use any valid email and password on the staff login screen. The demo does not send credentials anywhere and uses sample data only.

## Important

The UI and interactions are complete frontend previews. Authentication, database, file storage, email, payments, and accounting integrations still need a backend connection before production use.
