# VisaMOTion Website Build

## Files

- `visamotion-visa.html` - New visa-focused home page with visa services, route finder, application tracker, news, FAQ, consultation modal, and responsive motion.
- `visamotion-services.html` - Visa service routes and four-step process page.
- `visamotion-news.html` - Immigration news and practical guides page with filters and newsletter signup.
- `visamotion-consult.html` - Consultation enquiry page with a complete responsive form flow.
- `visamotion-admin.html` - Visa operations workspace with applications, deadlines, documents, news studio, activity, and responsive navigation.
- `visamotion-website.html` - Earlier public frontend preview retained for reference.
- `visamotion-staff-admin.html` - Earlier staff frontend preview retained for reference.

## Demo access

The internal operations page uses sample data and local interactions only. It does not send credentials anywhere.
